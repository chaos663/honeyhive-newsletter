3월 한 달 만에 프런티어 AI 모델 3개가 5일 간격으로 쏟아졌다. DeepSeek V4(3/3), GPT-5.4(3/5), Claude Opus 4.6(3/8). 경쟁 자체보다 중요한 건 이 모델들이 공통적으로 가리키는 방향이다—**'대화형 AI'는 끝났고, '행동하는 AI'가 시작됐다.** 에이전트가 화면을 직접 제어하고, 코드를 스스로 커밋하고, 광고를 보여주며 수익화한다. AI는 도구에서 플랫폼으로, 플랫폼에서 인프라로 전환 중이다.

---

## 🤖 3월 모델 3연전: GPT-5.4 vs Claude Opus 4.6 vs DeepSeek V4

3월 첫 2주, AI 모델 시장에서 전례 없는 동시 출시 경쟁이 벌어졌다.

- **무슨 일**: DeepSeek V4(3/3, 1조 파라미터 MoE·오픈웨이트), GPT-5.4(3/5, SWE-bench Pro 57.7%·네이티브 컴퓨터 제어), Claude Opus 4.6(3/8, SWE-bench Verified 80.8%·Claude Code 통합)이 5일 안에 모두 출시됐다. 세 모델 모두 100만 토큰 컨텍스트를 지원한다.
- **왜 지금**: GPT-5 출시 이후 "다음 도약은 추론"이라는 합의가 업계에 형성됐고, 각 사가 동시에 '추론+에이전트' 도약 타이밍을 잡으면서 발표가 겹쳤다. DeepSeek V4는 가격으로 승부—GPT-5.4 대비 약 50배 저렴하다.
- **업계 반응**: 코딩 벤치마크에서 Claude Opus 4.6이 80.8%로 독보적 1위를 차지하자, 이전 #QuitGPT 운동과 맞물려 Anthropic 앱이 App Store 1위에 오르며 사용자 기반이 전분기 대비 60% 성장했다(getaiperks.com). GPT-5.4는 에이전트 빌더에게, DeepSeek V4는 비용 민감형 스타트업에게 각각 집중되는 세분화 양상이 뚜렷하다.
- **전망**: 조건 A(코딩 자동화 시장 성숙)—Claude Code가 엔터프라이즈 SDLC 표준으로 자리잡고, Anthropic의 고가 Opus 4.6($25/MTok output)이 정당화된다. 조건 B(비용 경쟁 심화)—DeepSeek V4 오픈웨이트 생태계가 파인튜닝·자체 배포로 확산되며 API 단가 자체가 붕괴 압력을 받는다. 두 시나리오는 시장 세그먼트별로 동시에 전개될 가능성이 높다.

> **한 줄 인사이트**: 모델 능력 차이는 좁혀지고 있다—이제 경쟁의 축은 '얼마나 잘 하나'에서 '얼마나 싸게, 얼마나 에이전트처럼 하나'로 이동했다.

## ⚡ Claude, 컴퓨터 마우스·키보드·화면 직접 제어 출시

AI 에이전트가 '브라우저 안'을 벗어나 '데스크톱 전체'를 제어하게 됐다.

- **무슨 일**: Anthropic이 Claude Code Desktop 및 Cowork와 연동해 실제 컴퓨터의 마우스·키보드·화면을 직접 제어하는 기능을 출시했다(긱뉴스, 2026-03-24). 어떤 앱이든 Claude가 직접 조작 가능하며 Dispatch와 함께 사용 시 다중 에이전트 체인 구성도 된다.
- **왜 지금**: GPT-5.4도 같은 시기 네이티브 컴퓨터 제어를 출시하며 '에이전트 기반' 경쟁이 코드 생성을 넘어 실행 자동화로 확장됐다. RPA(로봇 프로세스 자동화) 시장을 AI가 잠식하는 본격적 전환점이다.
- **업계 반응**: 개발자 커뮤니티에서는 흥분과 우려가 동시에 나온다. 보안 연구자들은 프롬프트 인젝션 공격이 AI 컴퓨터 제어와 결합될 때의 위험성을 제기하고 있다. 텐센트가 WeChat에 OpenClaw 에이전트(ClawBot)를 통합한 것처럼, 수십억 사용자 규모 앱에서 에이전트 제어가 기본값이 되는 흐름이 가속화 중이다(Reuters, 2026-03-22).
- **전망**: 조건 A(샌드박스 표준화 성공)—컴퓨터 제어 AI가 엔터프라이즈 IT 자동화 시장(글로벌 RPA 시장 규모 2025년 기준 약 130억 달러)을 빠르게 대체. 조건 B(보안 사고 발생)—규제 당국이 개입하며 에이전트 컴퓨터 접근 권한에 대한 명시적 인가 프로세스 의무화. 백악관이 AI 국가 프레임워크를 추진 중인 시점과 겹쳐 규제 논의가 빨라질 가능성이 있다.

> **한 줄 인사이트**: AI가 화면을 보고 클릭하는 순간, 자동화의 범위는 'API 있는 서비스'에서 '모든 소프트웨어'로 확장된다—이건 RPA 산업 전체의 사망 선고에 가깝다.

## 💰 OpenAI의 수익화 전환: 광고 도입 + 8,000명 채용

OpenAI가 플랫폼 전략으로 전환하며 미디어 기업의 길을 걷기 시작했다.

- **무슨 일**: OpenAI는 미국 내 ChatGPT 무료·Go 사용자 전체에게 수 주 안에 광고를 표시한다고 발표했다. 광고 기술 파트너로 Criteo와 계약했다(Reuters, 2026-03-21). 동시에 연말까지 직원 수를 현재의 두 배인 8,000명으로 늘리는 채용 계획을 공개했다(Reuters, 2026-03-21).
- **왜 지금**: GPT 추론 비용은 지속적으로 상승하는 반면, 구독 수익만으로는 컴퓨팅 비용을 충당하기 어렵다는 구조적 압박이 가속화됐다. Britannica·Merriam-Webster가 학습 데이터 무단 사용으로 OpenAI를 연방법원에 제소하는 등 법률 비용도 증가 중이다(Reuters, 2026-03-22).
- **업계 반응**: Anthropic은 여전히 광고 없는 구독 모델을 유지하며 '안전성과 무결성' 포지셔닝을 강화한다. 일부 사용자들은 "AI 검색에 광고가 붙으면 결과가 편향될 것"이라는 우려를 표명하고 있다. Google도 AI Ultra 구독 기반으로 Workspace Gemini를 확대(2026-03-10)하며 구독 vs 광고 진영이 선명해졌다.
- **전망**: 조건 A(광고 수익 안착)—OpenAI가 미디어 플랫폼 역할을 겸하며 구글형 이중 수익 모델(구독+광고) 확립. 조건 B(사용자 이탈)—이미 #QuitGPT로 Claude에 250만 명이 이동한 전례처럼, 광고에 반감을 가진 파워유저들이 광고 없는 경쟁 제품으로 이동해 프리미엄 사용자 기반이 약화.

> **한 줄 인사이트**: ChatGPT에 광고가 붙는다는 건 'AI 어시스턴트'가 Google처럼 '광고 기반 미디어'가 된다는 뜻—AI 중립성에 대한 신뢰 문제가 본격적으로 대두될 것이다.

## 🔗 이슈 연결 분석

> 이번 주 AI 뉴스를 관통하는 하나의 흐름: **AI의 '플랫폼화'와 그에 따른 권력 집중**.

모델 3연전은 표면상 기술 경쟁이지만, 그 뒤에는 **에이전트 실행권 선점** 싸움이 있다. Claude가 컴퓨터를 직접 제어하고, GPT-5.4가 데스크톱 앱을 조작하며, DeepSeek가 오픈웨이트로 무한 복제된다. 동시에 OpenAI는 광고를 붙이고 8,000명을 채용하며 '규모의 플랫폼'으로 전환 중이다. 백악관이 주정부 AI 규제를 연방 단일 프레임워크로 선점하려는 움직임도 이 생태계에서 '규칙 제정자'가 누가 될지를 두고 벌어지는 권력 싸움이다. 개발자·기업 입장에서는 지금이 스택을 선택할 결정적 시점이다—어느 에이전트 플랫폼이 자사 인프라의 기반이 될지를 선택해야 한다.

## 🎯 오늘의 핵심 시그널

1. **에이전트 전쟁의 전선 이동**: 코딩 벤치마크 경쟁은 이미 끝났다. 이제 전선은 '누가 데스크톱을 먼저 장악하는가'로 이동했다—Claude와 GPT-5.4 모두 컴퓨터 직접 제어를 동시에 출시한 건 우연이 아니다.
2. **DeepSeek V4의 가격 파괴**: GPT-5.4 대비 50배 저렴한 오픈웨이트 모델이 시장에 존재한다는 사실 자체가, API 단가를 기반으로 한 모든 SaaS 비즈니스 모델의 전제를 흔든다.
3. **ChatGPT 광고화 = AI 신뢰의 새 시험대**: AI 어시스턴트가 광고 수익을 위해 특정 답변을 편향시킬 가능성—이 우려가 업계 표준과 규제 논의를 촉발시킬 구조적 이슈다.
